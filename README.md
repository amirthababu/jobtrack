# JobTrack - Job Application Management System

JobTrack is a full-stack web application designed to help users manage and track their job applications, interviews, career preferences, and job-skill matching in one place.

## Features

- User registration and login
- JWT-based authentication
- Secure password encryption using BCrypt
- Add, edit, view, and delete job applications
- Track application status
- Search and filter job applications
- Interview scheduling and tracking
- Dashboard statistics and analytics
- User profile and career preferences
- AI-based job skill matching
- Identify matched and missing skills from job descriptions
- REST APIs using Spring Boot
- MySQL database integration
